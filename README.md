# SERANEX V2 (Seeduwa Base Architecture)

Elite Digital Engineering Portfolio built with Next.js 15, Tailwind CSS, and Framer Motion.

## 🚀 Quick Start

1.  **Install Dependencies:**
    ```bash
    npm install
    ```

2.  **Run Development Server:**
    ```bash
    npm run dev
    ```

3.  **Open Localhost:**
    Visit [http://localhost:3000](http://localhost:3000)

## 🛠 Tech Stack
-   **Framework:** Next.js 15 (App Router)
-   **Styling:** Tailwind CSS
-   **Animation:** Framer Motion (Page transitions & Preloader)
-   **Icons:** Lucide React
-   **Font:** Orbitron & Inter

## 📂 Project Structure
-   `/src/app`: Main pages (Home, Services, Portfolio)
-   `/src/components`: Reusable UI (Navbar, Footer, Preloader)
-   `/src/lib`: Helper functions (API calls)

## 🐺 "Survivor's Guide" Protocols
-   **Images:** Must use `referrerPolicy="no-referrer"` to prevent hotlink blocking.
-   **Config:** Use `next.config.mjs` (not .ts) to avoid Vercel build errors.
-   **Case Sensitivity:** All filenames are lowercase.
